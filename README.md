# White-papers

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24024690.svg)](https://doi.org/10.5281/zenodo.24024690)
The scientific questions that I like, researched and sometimes proven using AI.

## Layout

Notes are filed by field using the [arXiv taxonomy](https://arxiv.org/category_taxonomy): `<archive>/<subject class>/<note>/`, e.g. `cs/CC/` for computational complexity, `math/NT/` for number theory. Each note folder holds the note (`note.md`), the scripts that reproduce its numbers, and a `CITATION.cff`.

## Provenance

These notes are produced by AI models (named in each note) in sessions I direct. I am not a mathematician; what I check myself is stated in each note's "What has and has not been checked" section, usually that the scripts run and reproduce the reported numbers. Results depend on the sources they cite. Corrections and counterexamples are welcome as issues; I will mark a note as withdrawn or corrected if one holds.
